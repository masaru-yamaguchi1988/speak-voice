読み上げ本文は保存しません。エラー表示の診断IDと同じIDで、連続した試行を追跡できます。

ブラウザや他のエージェントアプリから以下のエンドポイントへPOST送信することで、任意テキストを即座に音声再生できます。

POST /api/hook/speak
{"engine":"voicevox", "speaker":"1", "text":"読み上げたい文章"}

下のボタンをブックマークバーへドラッグしてください。ページ上で文章を選択して押すと、現在の音声設定で読み上げます。

🔊 選択テキストを読み上げ

選択テキストをコピーした後、次のコマンドをRaycast、Alfred、macOSショートカットなどに登録できます。

speak-voice-clip --wait

テキストを直接渡す場合：

speak-voice hook "読み上げたい文章" --wait
